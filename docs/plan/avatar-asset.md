# Аватар карты тела на iPhone

Вкладка «Карта тела» строит изображение на устройстве из треугольной модели `ios/EtoTy/BodyAvatar.mesh`. Нативный растеризатор выводит изображение в UIKit. Он вычисляет глубину, нормали, освещение, прозрачность оболочки и ближайший орган под каждым пикселем для текущего ракурса. Поворот непрерывный. В полном росте видны волосы и обе стопы. Модель для экрана содержит 33 439 вершин и 65 024 треугольника.

Файл `BodyAvatar.usdz` сохраняет исходную фигуру высотой 1,694 м. Ось +Y направлена вверх, +Z — вперёд. Оба файла воспроизводит один скрипт. Для экрана он дополнительно формирует коронарные ветви, рёбра, позвонки и пряди волос.

## Геометрия и происхождение

Основа фигуры — MakeHuman hm08. В заголовке исходного OBJ указаны Data Collection AB, Joel Palmius и Jonas Hauquier и посвящение CC0 в сентябре 2020 года. Использована только группа `body`. Скрипт изменяет положение рук и ног, разделяет оболочку и лицо, формирует волосы из верхней части головы и добавляет глаза, брови и внутренние органы. Стилизованные органы служат для навигации по документам. [Исходный OBJ фиксированной версии](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj) · [Лицензии MakeHuman](https://www.makehumancommunity.org/about/license.html)

| Область | Узлы в USDZ |
| --- | --- |
| Сердце | `Heart`, `AorticArch`, `PulmonaryTrunk` |
| Печень | `Liver` |
| Почки | `KidneyLeft`, `KidneyRight` |

Выбранный орган подсвечивается отдельным цветом. При увеличении камера следует по высоте за выбранным органом. Кнопка со стрелкой возвращает вид спереди в полный рост.

## Сборка

Для пересборки нужны Python 3, NumPy и файл `base.obj` из указанной версии. Скрипт проверяет SHA-256 исходника.

```sh
python3 scripts/build_body_avatar.py /path/to/base.obj ios/EtoTy/BodyAvatar.usdz
```

SHA-256 экранной модели — `664dbd3d5f4e6d21deaef34ea9c51c528e6f09047f8454963768343f2806900b`. SHA-256 USDZ — `d4f9ec521fe3a51fee91a17066f8c73cb3763fbc609bcb0e5b669a90066eb502`. Xcode включает файлы из синхронизированной папки `ios/EtoTy` в цель приложения.

## Проверка на iPhone

Открыть «Карта тела». Проверить видимость головы и стоп, повернуть фигуру в обе стороны и увеличить двумя пальцами. Коснуться сердца и печени спереди, обеих почек сзади. Заголовок карточки должен совпадать с выбранной областью. Открыть её документы и сводку. Вернуться к исходному ракурсу. С VoiceOver выбрать область кнопкой под фигурой и проверить доступные действия поворота и масштаба на самой фигуре.

Тест интерфейса `BodyAvatarUITests` проверяет пиксели головы, туловища, стоп и подсветки сердца на скриншоте. Затем он проверяет изменение пикселей после поворота, поворот, увеличение, сброс ракурса, выбор печени касанием и выбор почек кнопкой.
