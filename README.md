# Это ты

Личный iPhone-пилот сопровождения здоровья. Можно поручить одно дело, выбрать время контакта и закрыть приложение. В срок вопрос появится в диалоге. Если разрешены системные уведомления, iPhone также покажет нейтральное приглашение. Вложения, переписка и договорённости находятся в локальном контейнере приложения на этом устройстве.

## Что попробовать на первом запуске

1. Открой «Диалог» и напиши или продиктуй через клавиатуру «Хочу собрать документы к приёму». Следующей фразой попроси «Напомни через две минуты». Проверь предложенное время и подтверди его.
2. Разреши уведомления, сверни приложение, затем открой его из уведомления или самостоятельно. Ответь на появившийся вопрос. Закрой и снова открой приложение, проверь, что сохранились ответ и состояние договорённости.
3. Через скрепку приложи вымышленный PDF или фото. Открой оригинал, укажи относящуюся к нему область тела и при желании запиши дату исследования и фрагмент со страницей. Посмотри основание на «Карте тела» и в «Моём уровне». Архив позволяет исправить привязку и удалить материал.
4. Открой справочник профилактики. В нём можно сравнить вымышленные примеры и перейти к источнику. Через меню доступен отдельный демонстрационный профиль. Удаление личного профиля снимает локальное напоминание и очищает его архив.

Диктовка зависит от системных настроек клавиатуры. Код синхронизируется через GitHub, личные записи остаются на конкретном телефоне. Медицинская оценка персонального риска и обмен данными с клиниками относятся к следующим этапам. [План проекта](docs/plan/README.md) · [Кликабельный макет](docs/plan/three-screens.html).

## iPhone и среда разработки

На своём Mac открой [setup-iphone.command](setup-iphone.command) двойным кликом в Finder. Скрипт открывает страницу Xcode, если программы ещё нет, ждёт установки и системных подтверждений, проверяет iOS Simulator, при необходимости скачивает его и собирает проект. Глобальный выбор Xcode на Mac менять не требуется.

Нативный проект — [EtoTy.xcodeproj](ios/EtoTy.xcodeproj). Целевая платформа iOS 17+, формат проекта Xcode 16+. Для запуска выберите в Xcode схему EtoTy, симулятор iPhone и Run. На своём устройстве выберите команду подписи в Signing & Capabilities и доступный идентификатор приложения. При первом запуске открывается пустой личный профиль.

Из корня репозитория на Mac:

| Команда | Что проверяет или создаёт |
|---|---|
| `make check` | Структуру Xcode-проекта, компиляцию общих SwiftUI-представлений на macOS SDK, переходы уровня, фильтрацию записей, PDF и прежний пилот Mac. Нужны Apple Command Line Tools с macOS 14+ SDK. |
| `make ios-smoke` | Создаёт временный симулятор iPhone, запускает интерфейсный тест с перезапуском приложения и удаляет этот симулятор. |
| `make ios-build` | Компилирует приложение для симулятора через полный Xcode с iOS SDK, без подписи. |
| `make sample-brief` | Создаёт локальный вымышленный PDF для врача в `local-data/visit-example.pdf`. На iPhone тот же генератор доступен через «Карта тела → Собрать сводку врачу». |
| `make db-check` | На машине с Docker запускает одноразовый PostgreSQL 18, применяет первую миграцию, проверяет изоляцию двух тестовых профилей, ссылки и каскадное удаление. Сетевой порт не публикуется. |

## Попробовать пилот напоминаний на Mac

1. Открой `start.command` двойным кликом в Finder или выполни `./start.command` из папки проекта. macOS может запросить разрешение Terminal управлять приложением «Напоминания».
2. Выбери «Поручить вопрос», впиши, например, «На сколько вечеров за неделю мне хватило сил?» и выбери «Через 2 минуты».
3. Закрой прототип. В приложении «Напоминания» в списке «Это ты · сопровождение» появится запись с вопросом и сроком. Для баннера разреши уведомления для «Напоминаний» в macOS и проверь режим фокусирования.
4. После уведомления открой запись. В заметке можно добавить ответ. В самой записи можно сменить срок или отметить дело выполненным. При следующем запуске выбери «Открыть мои договорённости».

Для первого прохода хватит выдуманного вопроса. Текст записывается только в «Напоминания» учётной записи по умолчанию на этом Mac. Если это iCloud и синхронизация «Напоминаний» включена, запись может появиться и на других твоих устройствах. GitHub хранит исходники. Не добавляй в коммиты выписки, ответы, ключи и выгрузки. Разбор документов, ИИ и самостоятельный выбор медицинских действий в этой версии ещё не реализованы.

## Разработка на двух Mac

На каждом Mac один раз скопируй HTTPS-адрес репозитория через **Code** на GitHub, выполни `git clone <адрес>`, открой `eto-ty` в Codex. Для закрытого репозитория нужен GitHub-аккаунт с доступом, в том числе для Git на этом Mac.

Перед изменениями выполни `git pull --ff-only` на рабочей ветке. В конце сессии проверь `git status`, добавь нужные файлы через `git add <файлы>`, выполни `git commit -m "Что изменилось"` и `git push`. На другой машине открой ту же ветку и выполни `git pull --ff-only`. Вместе с кодом переносится этот README. Переписка Codex и локальные настройки в коммиты не входят.

## Проверка на Mac

`osascript -l JavaScript tests/run.js app/check-in.js` проверяет планирование и сценарии создания, отмены и повторного открытия на имитации «Напоминаний». Для проверки системного разрешения и доставки баннера пройди двухминутный сценарий выше.
