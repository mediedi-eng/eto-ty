# Это ты

Личный iPhone-пилот сопровождения здоровья. Можно поручить одно дело, выбрать время контакта и закрыть приложение. В срок вопрос появится в диалоге. Если разрешены системные уведомления, iPhone также покажет нейтральное приглашение. Вложения, переписка и договорённости находятся в локальном контейнере приложения на этом устройстве.

## Что попробовать на первом запуске

1. Открой «Диалог» и напиши или продиктуй через клавиатуру «Хочу собрать документы к приёму». Следующей фразой попроси «Напомни через две минуты». Проверь предложенное время. Для одного напоминания достаточно его подтвердить. Если хочешь продолжать разговор каждую неделю, включи повторение. При отсутствии ответа вопросы не накапливаются.
2. Разреши уведомления, сверни приложение, затем открой его из уведомления или самостоятельно. Ответь на появившийся вопрос. Закрой и снова открой приложение, проверь, что сохранились ответ и состояние договорённости.
3. Через скрепку выбери вымышленный PDF, фото или отсканируй бумажные страницы камерой iPhone. В архиве открой оригинал, выбери страницу и нажми «Найти текст на странице». Сверь найденную строку, подтверди цитату, дату и подходящую область тела. Эти сведения появятся на карте тела и в уровне изученности.
4. Вернись в «Диалог». По новой записи приложение предложит сверить источник или подготовить вопрос к приёму. Предложение можно принять или скрыть. Если у тебя уже есть дело, к нему можно привязать документ, сохранив договорённый срок.
5. Напиши «Найди ЭКГ», «Что мы знаем о почках?» или «Покажи последние документы». Поиск учитывает название, выбранную область, дату исследования и подтверждённый текст. Из результата можно открыть оригинал на странице цитаты.
6. Открой «Сводку к приёму» в меню профиля. Можно заранее записать свои вопросы врачу и вернуться к ним позже. Отметь вопросы и источники, которые хочешь показать, прочитай предпросмотр и сохрани выбранный текст в PDF.
7. В справочнике профилактики можно сравнить вымышленные примеры и перейти к источнику. Через меню также доступен демонстрационный профиль. Удаление личного профиля снимает локальное напоминание и очищает архив.

В меню можно описать нужное действие своими словами. Подбор раздела использует локальную модель Apple только на совместимом устройстве с доступной моделью и поддерживаемым языком. В остальных случаях раздел выбирается вручную. Диктовка зависит от системных настроек клавиатуры. Код синхронизируется через GitHub, личные записи остаются на конкретном телефоне. Медицинская оценка персонального риска и обмен данными с клиниками относятся к следующим этапам. [План проекта](docs/plan/README.md) · [Кликабельный макет](docs/plan/three-screens.html).

## iPhone и среда разработки

На своём Mac открой [setup-iphone.command](setup-iphone.command) двойным кликом в Finder. Скрипт открывает страницу Xcode, если программы ещё нет, дожидается установки Xcode и среды iOS Simulator, собирает проект и запускает приложение в отдельном симуляторе «EtoTy Development». При следующем запуске используется тот же симулятор с сохранённым профилем. Глобальный выбор Xcode на Mac менять не требуется.

Нативный проект — [EtoTy.xcodeproj](ios/EtoTy.xcodeproj). Целевая платформа iOS 17+, формат проекта Xcode 16+. Для ручного запуска в Xcode выбери схему EtoTy, симулятор iPhone и Run. На своём устройстве выберите команду подписи в Signing & Capabilities и доступный идентификатор приложения. При первом запуске открывается пустой личный профиль.

Из корня репозитория на Mac:

| Команда | Что проверяет или создаёт |
|---|---|
| `make check` | Структуру Xcode-проекта, компиляцию SwiftUI на macOS SDK, сохранение и удаление профиля, расписание, импорт документов, источники, экспорт PDF и прежний пилот Mac. Нужны Apple Command Line Tools с macOS 14+ SDK. |
| `make ios-smoke` | Создаёт временный симулятор iPhone, запускает интерфейсный тест с перезапуском приложения и удаляет этот симулятор. |
| `make ios-build` | Компилирует приложение для симулятора через полный Xcode с iOS SDK, без подписи. |
| `make sample-brief` | Создаёт локальный вымышленный PDF для врача в `local-data/visit-example.pdf`. Тот же генератор используется для личной сводки и вымышленного примера в меню приложения. |
| `make db-check` | На машине с Docker запускает одноразовый PostgreSQL 18, применяет первую миграцию, проверяет изоляцию двух тестовых профилей, ссылки и каскадное удаление. Сетевой порт не публикуется. |

## Попробовать пилот напоминаний на Mac

1. Открой `start.command` двойным кликом в Finder или выполни `./start.command` из папки проекта. macOS может запросить разрешение Terminal управлять приложением «Напоминания».
2. Выбери «Поручить вопрос», впиши, например, «На сколько вечеров за неделю мне хватило сил?» и выбери «Через 2 минуты».
3. Закрой прототип. В приложении «Напоминания» в списке «Это ты · сопровождение» появится запись с вопросом и сроком. Для баннера разреши уведомления для «Напоминаний» в macOS и проверь режим фокусирования.
4. После уведомления открой запись. В заметке можно добавить ответ. В самой записи можно сменить срок или отметить дело выполненным. При следующем запуске выбери «Открыть мои договорённости».

Для первого прохода хватит выдуманного вопроса. Текст записывается только в «Напоминания» учётной записи по умолчанию на этом Mac. Если это iCloud и синхронизация «Напоминаний» включена, запись может появиться и на других твоих устройствах. GitHub хранит исходники. Не добавляй в коммиты выписки, ответы, ключи и выгрузки. Разбор документов, ИИ и самостоятельный выбор медицинских действий в этой версии ещё не реализованы.

## Разработка на двух Mac

На каждом Mac один раз скопируй HTTPS-адрес репозитория через **Code** на GitHub, выполни `git clone <адрес>`, открой `eto-ty` в Codex. Для закрытого репозитория нужен GitHub-аккаунт с доступом, в том числе для Git на этом Mac.

Перед изменениями выполни `git pull --ff-only` на рабочей ветке. В конце сессии проверь `git status`, добавь нужные файлы через `git add <файлы>`, выполни `git commit -m "Что изменилось"` и `git push`. На другой машине открой ту же ветку и выполни `git pull --ff-only`. Вместе с кодом переносится этот README. Переписка Codex и локальные настройки в коммиты не входят.

## Проверка на Mac

`osascript -l JavaScript tests/run.js app/check-in.js` проверяет планирование и сценарии создания, отмены и повторного открытия на имитации «Напоминаний». Для проверки системного разрешения и доставки баннера пройди двухминутный сценарий выше.
